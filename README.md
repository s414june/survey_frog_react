## 作答進度

沿用 footer 原有的進度條與百分比，不另外新增進度元件。

- 百分比 = 已回答題數 ÷（必填題數＋已填寫的選填題數）× 100，四捨五入為整數。
- 計算整份問卷的可見題目；未填寫的選填題、說明文字及隱藏題目不計入分母。
- 空字串／純空白視為未回答；單選值 `0` 仍算已回答。
- 選擇「需要報修」會將兩個報修題目納入分母；改成「不需要」會同時排除其題數與答案計數。
- 目前有 7 題必填，顯示報修題目時為 9 題必填；每填寫一題選填題，分子與分母各增加 1，清空時各減少 1。
- 必填題全部答完，即使選填題留白也會顯示 100%。題目設定改動後會自動重新計算。
- 進度代表已填寫比例，不代表已通過驗證；完成頁也不強制顯示 100%。

## 表單驗證

使用 React Hook Form 管理跨頁答案，透過 `@hookform/resolvers` 串接 Zod。

- 換頁按鈕、footer 下一頁及 Enter 送出都先驗證目前頁面；最後送出驗證整份問卷。
- 必填題不能空白，星星評分及選項須有效，隱藏題目不參與驗證。
- 電子信箱與電話為選填；有填寫時才驗證格式。電話接受 7–20 個數字／空白／括號／連字號及開頭的 `+`，且至少包含 7 位數字。
- 下拉選單初始為「請選擇」，尚未選擇不算已回答。
- 跨頁與瀏覽器上一頁／下一頁保留答案；隱藏題目的答案保留但不計數，重新顯示時恢復。
- 答案僅存於本次開啟頁面的記憶體，重新整理會重設；目前送出仍為原有的完成頁導向，未串接後端儲存。

題目設定：`src/page-settings.json`。驗證與進度規則：`src/utils/survey.ts`。
